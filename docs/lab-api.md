# API เซนเซอร์ภายนอก lab.plotnexuslab.com — คู่มือใช้งาน

เอกสารนี้สรุปว่า 6 ลิงก์ของ lab ให้ข้อมูลอะไร หน้าตา JSON เป็นยังไง และฟาร์มมี่เอาไปใช้ตรงไหน
โครงสร้างด้านล่างมาจากโค้ดที่เขียนคู่กับ API จริง (`backend/main.py` ส่วน "แหล่งข้อมูลเซนเซอร์ภายนอก")

- เรียกทุกอันด้วย `GET` + พารามิเตอร์ `key=<คีย์อ่าน>` (คีย์ขึ้นต้น `labro_`)
- คีย์เก็บใน `.env` ชื่อ `LAB_API_KEY` — ห้ามใส่ในโค้ดหรือฝั่งหน้าเว็บ
- คีย์ชุดเดิม (`labro_3k90…`) **ถูกตัดสิทธิ์แล้ว** ทุกลิงก์ตอบ `{"error": "ไม่มีสิทธิ์เข้าข้อมูลชุดนี้"}` ต้องขอคีย์ใหม่
- ชื่อฟิลด์ใน JSON เป็น**ภาษาไทย**ทั้งหมด

---

## 1) `/api/sources` — มีชุดข้อมูลอะไรให้ดูบ้าง

```
GET /api/sources?key=<KEY>
```

```jsonc
{
  "ชุดข้อมูล": [
    { "id": "soil",    "ชื่อ": "ดิน แสลงพัน" },
    { "id": "pig",     "ชื่อ": "เล้าหมู กำแพงเพชร" },
    { "id": "weather", "ชื่อ": "เสาอากาศ แสลงพัน" },
    { "id": "mine",    "ชื่อ": "พื้นที่ของฉัน", "ต้องระบุ table": true }
  ]
}
```

- `id` เอาไปใส่เป็น `source=` ของลิงก์อื่น
- ชุดที่มี `"ต้องระบุ table": true` คือพื้นที่ของเราเอง ต้องถามตารางต่อที่
  `GET /api/tables?key=<KEY>&source=mine` → `{"ตาราง": ["farmy", ...]}`
  แล้วเรียกลิงก์อื่นด้วย `source=mine&table=farmy`

## 2) `/api/measures` — ชุดนั้นวัดอะไรได้บ้าง

```
GET /api/measures?key=<KEY>&source=pig
```

```jsonc
{
  "วัดอะไรบ้าง": [
    { "id": "<id จริงของเซนเซอร์>", "ชื่อ": "อุณหภูมิ", "หน่วย": "°C", "รหัสสั้น": "temperature" }
  ]
}
```

- `รหัสสั้น` ใช้ข้ามชุดได้ (เช่น `temperature` ใช้ได้ทุกชุด) ส่วน `id` เป็นของเฉพาะชุดนั้น
- `/api/series` ต้องการ **`id` จริง** — ฝั่งเราแปลงรหัสสั้น → id ให้เอง

## 3) `/api/locations` — ชุดนั้นมีกี่จุดติดตั้ง

```
GET /api/locations?key=<KEY>&source=soil
```

```jsonc
{ "จุดติดตั้ง": [ { "id": "<รหัสจุด>", "ชื่อ": "เล้า R" } ] }
```

ใส่ `location=<id>` เพิ่มในลิงก์ `latest` / `series` / `summary` เพื่อกรองเฉพาะจุดนั้น

## 4) `/api/latest` — ค่าล่าสุดทุกเซนเซอร์ในชุดนั้น

```
GET /api/latest?key=<KEY>&source=pig[&location=<id>]
```

```jsonc
{
  "ชุดข้อมูล": "เล้าหมู กำแพงเพชร",
  "อัปเดตล่าสุด": "2026-09-23T03:10:00Z",     // ISO, UTC
  "ค่า": [
    {
      "id": "<id เซนเซอร์>", "ชื่อ": "อุณหภูมิ", "ค่า": 31.2, "หน่วย": "°C",
      "จุดติดตั้ง": "<รหัสจุด>", "ชื่อจุด": "เล้า R", "เวลา": "2026-09-23T03:10:00Z"
    }
  ]
}
```

หนึ่งชุดมีได้หลายจุด — `ค่า` เป็นลิสต์รวม ต้องจัดกลุ่มด้วย `จุดติดตั้ง` เอง

## 5) `/api/series` — ค่าย้อนหลังสำหรับวาดกราฟ

```
GET /api/series?key=<KEY>&source=pig&measure=<id จริง>&hours=24[&location=<id>]
```

```jsonc
{
  "ชุดข้อมูล": "เล้าหมู กำแพงเพชร",
  "ชื่อ": "อุณหภูมิ",          // บางครั้งใช้คีย์ "วัด"
  "หน่วย": "°C",
  "ช่วงเวลา": "24 ชั่วโมงล่าสุด",
  "เส้น": [
    {
      "จุดติดตั้ง": "<รหัสจุด>", "ชื่อจุด": "เล้า R",
      "ข้อมูล": [ { "t": "2026-09-23T03:10:00Z", "v": 31.2 } ]   // v เป็น null ได้ = ไม่มีค่า
    }
  ]
}
```

หนึ่งจุดติดตั้ง = หนึ่งเส้นกราฟ · เวลาเป็น UTC ต้องแปลงเป็นเวลาไทยเอง

## 6) `/api/summary` — สรุปต่ำสุด/เฉลี่ย/สูงสุดของทุกค่า

```
GET /api/summary?key=<KEY>&source=pig&hours=24[&location=<id>]
```

```jsonc
{
  "ชุดข้อมูล": "เล้าหมู กำแพงเพชร",
  "ช่วงเวลา": "24 ชั่วโมงล่าสุด",
  "สรุป": [
    {
      "id": "<id เซนเซอร์>", "ชื่อ": "อุณหภูมิ", "หน่วย": "°C",
      "ต่ำสุด": 27.4, "เฉลี่ย": 30.1, "สูงสุด": 34.8,
      "จุดติดตั้ง": "<รหัสจุด>", "ชื่อจุด": "เล้า R"
    }
  ]
}
```

ยิงครั้งเดียวได้ทุกค่า — ถ้าใช้ `series` ต้องยิงทีละค่าสิบกว่าครั้ง

## ส่งข้อมูลของเราขึ้น lab (ไม่ใช่คีย์ `labro_`)

`POST /write` ด้วยบัญชี lab (`LAB_USER` / `LAB_PASSWORD`) รูปแบบ line protocol บรรทัดละค่า:

```
<ตาราง>,measure=<ชื่อค่า>,location=<จุด> value=<ตัวเลข>
```

เวลาให้เซิร์ฟเวอร์ประทับเอง

## ฟาร์มมี่ห่อไว้ให้แล้ว (เรียกของเราง่ายกว่า ไม่ต้องถือคีย์)

| ของเรา | ไปเรียก lab อะไร | คืนอะไร |
|---|---|---|
| `GET /lab/sources` | sources + measures + locations | `{enabled, sources:[{id,label,measures:[{id,label,unit,short}],locations:[{id,label}]}]}` |
| `GET /lab/latest?source=&location=` | latest | `{source,label,updated_at,sites:[{id,label,values:[{id,label,value,unit,time}]}]}` |
| `GET /lab/series?source=&measure=&hours=&location=` | series | `{source,measure,label,unit,hours,lines:[{site,label,points:[{t,v}]}]}` เวลาแปลงเป็นเวลาไทยแล้ว |
| `GET /lab/summary?source=&hours=&location=` | summary | แถวสรุปต่ำสุด/เฉลี่ย/สูงสุด |

- `measure` ของเรารับ**รหัสสั้น**ได้ (`temperature`) ไม่ต้องรู้ id จริง
- `hours` จำกัด 1–720 (30 วัน)
- แคช: latest 60 วิ · series/summary ตามที่ตั้งใน `LAB_SERIES_CACHE_SECONDS` · measures/locations 1 ชม.
- ไม่ตั้ง `LAB_API_KEY` = ปิดฟีเจอร์นี้ (`/lab/sources` คืน `enabled: false`) ระบบยังทำงานด้วยเซนเซอร์ของเราเองได้
- ค่าเหล่านี้ถูกแปลงเป็นข้อความสั้น ๆ ป้อนให้ Voice AI ด้วย จึงถามเป็นภาษาพูดได้ เช่น "ตอนนี้เล้า R ร้อนไหม" "สรุปกำแพงเพชรวันนี้"
