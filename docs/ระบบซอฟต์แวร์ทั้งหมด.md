## 2. เทคโนโลยีที่ใช้

**หลังบ้าน** — Python + FastAPI + Uvicorn
`pydantic` ตรวจรูปแบบข้อมูล · `httpx` เรียกบริการภายนอก · `fpdf2` + `pillow` ออกรายงาน PDF/รูป ·
`pypdf` + `python-docx` อ่านเอกสารเข้าคลังความรู้ · `google-genai` คุยกับ Gemini ·
`supabase` เป็นตัวคุยกับฐานข้อมูลผ่าน REST

**หน้าเว็บ** — React 18 + Vite + React Router + `recharts` (กราฟ)
ไม่ใช้เฟรมเวิร์ก UI สำเร็จรูป เขียน CSS เองทั้งหมด

**ฐานข้อมูล** — PostgreSQL 16 + PostgREST
PostgREST ทำให้ตารางคุยผ่าน REST ได้ หน้าตาเหมือน Supabase ทุกอย่าง
จึงย้ายจากคลาวด์มาอยู่ในกล่องได้โดยแทบไม่ต้องแก้โค้ด (สลับแค่ `SUPABASE_URL`)

## 3. สมองของระบบ — AI 5 ชั้น

คำถามเข้ามาแล้วไล่ลงทีละชั้นจนกว่าจะมีคนตอบได้ ไม่มีชั้นไหนตอบได้ก็ยังมีชั้นสุดท้ายเสมอ

| ชั้น | ใช้เมื่อไหร่ | ข้อดี |
|---|---|---|
| 1. ค้นอินเทอร์เน็ต (ผ่าน AI ของ CPF) | ถามข่าว ราคา การระบาด "ช่วงนี้" | ได้ข้อมูลสดที่ไม่มีในฟาร์มและในเอกสาร |
| 2. Gemini | คำถามทั่วไป | ตอบลื่น เข้าใจบริบท |
| 3. AI ของ CPF | Gemini ล่มหรือโควตาหมด | อยู่ในเครือข่ายบริษัท |
| 4. Ollama ในเครื่อง | ไม่มีอินเทอร์เน็ต | ฟรี ไม่จำกัดจำนวน |
| 5. กฎของเราเอง | ทุกชั้นบนล้ม | **ตอบได้เสมอ ไม่มีทางพัง** |

ก่อนถึงชั้นพวกนี้ ระบบเช็กก่อนว่าเป็น **คำสั่ง** หรือ **คำถาม** ถ้าเป็นคำสั่งบันทึกข้อมูล
จะใช้กฎตายตัวจับข้อมูลแทนการให้ AI เดา เพราะบันทึกผิดแล้วแก้ยาก

### คลังความรู้ (RAG)

เอกสารมาตรฐานราชการ 18 เล่ม ถูกหั่นเป็น 696 ท่อน แปลงเป็นดัชนีความหมายด้วยโมเดล
`multilingual-e5-base` ที่รันในเครื่อง (ไม่กินโควตา) เวลาถามจะหาท่อนที่ใกล้เคียงที่สุดมาแนบให้ AI

จุดที่ต้องระวังและแก้ไปแล้ว — ซ่อมอักษรไทยที่ PDF แปลงพัง · คัดท่อนขยะ (เลขหน้า หัวบท) ทิ้ง ·
ตั้งเกณฑ์ความใกล้เคียงที่ 0.85 จากการวัดจริง ไม่ใช่เดา

## 7. ช่องทางเข้าใช้งาน 4 ทาง

**1. เว็บ** — `fern.plotnexuslab.com` ใช้ได้ทั้งคอมและมือถือ

**2. พูดสั่งงาน (Voice AI)** — หน้าแรกเป็นช่องถาม กดไมค์พูดได้

- *ถาม* — อาการโรค วิธีฉีดวัคซีน ค่ามาตรฐาน เอกสาร ข้อมูลฟาร์มจริง
- *สั่งบันทึก* — ฉีดวัคซีน เพิ่มชุดหมู บันทึกอาการหลังฉีด
  พูดจบแล้วขึ้นตารางให้ดูทันทีว่าเก็บอะไรไว้ ช่องไหนยังขาด และกดแก้ไขเติมได้
- *สั่งส่ง* — ส่งงาน สรุป รายงาน เข้ากลุ่ม LINE
- *สั่งเปิดหน้า* — "เปิดหน้าแผนวัคซีน"

**3. LINE** — บอท `@159xyfzc`

- เช้า 07:00 มอบหมายงานแยกตามคน + วัคซีนที่ต้องฉีดวันนี้
- เย็น 18:30 สรุปฟาร์มวันนี้ (พร้อมลิงก์ไฟล์ PDF)
- ริชเมนู 3 ปุ่ม: รายงานวัคซีน · สรุปฟาร์ม · เปิดเว็บ
- พิมพ์คุยกับบอทได้

**4. กล่องถามที่ฝังในแดชบอร์ดอื่น** — ไฟล์เดียว 27 KB แปะ `<script>` บรรทัดเดียว
ถาม-ตอบอย่างเดียว กันการบันทึกข้อมูลไว้ที่ฝั่งเซิร์ฟเวอร์

## 8. ความปลอดภัยและสิทธิ์

**ด่านตรวจแบบปิดก่อน** — ทุกเส้นทางต้องล็อกอิน ยกเว้นที่อยู่ในรายการอนุญาตชัดเจน

| ระดับ | ทำอะไรได้ |
|---|---|
| คนนอก | อาการโรค · วิธีฉีดวัคซีน · สายพันธุ์ · ค่ามาตรฐาน · อากาศ · เอกสารมาตรฐาน |
| คนใน | ข้อมูลฟาร์มทั้งหมด บันทึกข้อมูล สั่งงาน |
| ผู้ดูแล | จัดการผู้ใช้ ตั้งค่าระบบ |

**รหัสผ่าน** เก็บเป็นค่าแฮช (PBKDF2) ไม่เก็บตัวจริง · ใส่ผิดหลายครั้งถูกล็อกชั่วคราว
**LINE webhook** ตรวจลายเซ็นทุกครั้ง · **ลิงก์รายงาน** ใช้คีย์ลับใน path
**คำสั่งเสียงที่เปลี่ยนข้อมูล** ต้องล็อกอิน และกล่องที่ฝังในเว็บอื่นถูกปิดสิทธิ์นี้ที่หลังบ้าน

## 9. การติดตั้งและการดูแล

**ทุกอย่างอยู่ในกล่อง box-fern** — เว็บ · API · ฐานข้อมูล · คลังเอกสาร · ฟอนต์และไอคอน
ไม่พึ่ง CDN ข้างนอก เปิดได้แม้เครือข่ายบล็อกเน็ตนอก

**สิ่งที่รันค้างอยู่ในกล่อง**

| โปรเซส | หน้าที่ |
|---|---|
| `uvicorn` | เว็บ + API พอร์ต 8000 |
| `postgres` | ฐานข้อมูล พอร์ต 5432 |
| `postgrest` | ทางเข้าข้อมูลแบบ REST พอร์ต 3001 |
| `box-keepalive.sh` | ตรวจทุกนาที อะไรตายปลุกเอง |
| `box-db-backup.sh` | สำรองฐานข้อมูลวันละครั้ง เก็บ 14 ชุด |
| `tailscaled` + `dropbear` | ช่องทางเข้าไปดูแลระบบ |

**ตัวตั้งเวลาจากข้างนอก** — GitHub Actions 2 งาน เรียก `/cron/*` ของเรา
(เช้า: มอบหมายงาน + วัคซีน + ตรวจอาการ · เย็น: สรุปฟาร์ม)

**บริการภายนอกที่ยังต้องพึ่ง** — Gemini · AI และเสียงพูดของ CPF · LINE ·
เซนเซอร์ `lab.plotnexuslab.com` · GitHub Actions
