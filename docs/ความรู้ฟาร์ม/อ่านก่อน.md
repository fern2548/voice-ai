# วางเอกสารที่อยากให้ AI รู้ไว้ในโฟลเดอร์นี้

วางไฟล์แล้วบอกในแชตว่า "วางเอกสารแล้ว" ระบบจะถูกนำเข้าคลังความรู้ให้

## ไฟล์ที่รองรับ

`.pdf` · `.docx` · `.txt` · `.md` — ขนาดไม่เกิน 10 MB ต่อไฟล์

ถ้าเอกสารยาวมาก (เกิน ~350 หน้า) ให้แบ่งเป็นหลายไฟล์

## ตั้งชื่อไฟล์ให้สื่อความ

ชื่อไฟล์จะกลายเป็นชื่อเอกสารในระบบ และ AI จะอ้างอิงชื่อนี้เวลาตอบ
ผู้ใช้จะได้รู้ว่าคำตอบมาจากเล่มไหน

```
ดี     มาตรฐานฟาร์ม-CP-2026.pdf
       ฉลากวัคซีนอหิวาต์สุกร.pdf
       SOP-ขั้นตอนหย่านม.docx

ไม่ดี  เอกสาร1.pdf
       scan_0012.pdf
```

## เอกสารที่มีประโยชน์มากที่สุด เรียงตามลำดับ

1. **SOP ของฟาร์มเราเอง** — วิธีทำงานเฉพาะของที่นี่
   สำคัญที่สุด เพราะไม่มีใครรู้นอกจากเรา AI หาจากที่อื่นไม่ได้
2. **ฉลาก / เอกสารกำกับวัคซีน** ที่ฟาร์มใช้จริง — โดส อายุที่ฉีด วิธีเก็บ
3. **คู่มือมาตรฐานฟาร์มของ CP** — ขั้นตอนที่ต้องทำตาม
4. **คู่มือกรมปศุสัตว์** — โรคระบาดและการแจ้งเหตุ

## สิ่งที่ไม่ควรวาง

- ไฟล์ที่มีรหัสผ่าน คีย์ หรือข้อมูลส่วนตัวของพนักงาน
- ไฟล์สแกนที่เป็นรูปล้วนและไม่มีตัวหนังสือให้อ่าน (ระบบดึงข้อความไม่ได้)
  ถ้ามีแต่แบบนี้ บอกได้ จะหาวิธีแปลงให้

## เอกสารในนี้จะถูกใช้ยังไง

ระบบหั่นเอกสารเป็นท่อนละประมาณ 900 ตัวอักษร แล้วทำดัชนีค้นหา
เวลาผู้ใช้ถาม ระบบจะค้นท่อนที่เกี่ยวข้องที่สุด 4 ท่อน
แนบให้ AI อ่านก่อนตอบ และให้บอกด้วยว่าอ้างจากเอกสารชื่ออะไร

ถ้าเอกสารไม่ได้พูดถึงเรื่องที่ถาม AI จะไม่อ้างว่ามาจากเอกสาร
