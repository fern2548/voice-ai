# AI ของ CPF — ถามอะไรได้บ้าง

เอกสารนี้สรุปจากการ **ทดสอบยิงจริง** กับบริการของ CPF เมื่อ 14–15 ตุลาคม 2026
ไม่ใช่การอ่านคู่มือ ทุกหัวข้อด้านล่างมีผลลัพธ์จริงกำกับ

ระบบของเราเรียกใช้ AI ตัวนี้เป็น **ตัวสำรอง** ต่อจาก Gemini
(ลำดับ: Gemini → CPF → Ollama → กฎของเราเอง)

---

## 1. ที่อยู่และวิธีเรียก

### ถาม-ตอบ

```
POST https://ota.plotnexuslab.com/ai/api/ask
X-API-Key: <คีย์>
Content-Type: application/json

{"q": "คำถาม", "level": 1}
```

ได้กลับมา

```json
{"ok": true, "answer": "...", "model": "qwen3:14b", "used_tools": false}
```

### เสียงพูดไทย

```
POST https://ota.plotnexuslab.com/ai/api/tts
X-API-Key: <คีย์>

{"text": "ข้อความที่จะให้อ่าน"}
```

ได้กลับมาเป็นลิงก์ไฟล์เสียง

```json
{"เสียง": "female",
 "ท่อน": [{"ข้อความ": "...", "ไฟล์": "xxx.wav", "จากแคช": true,
          "ลิงก์": "https://ota.plotnexuslab.com/ai/api/voice/xxx.wav"}]}
```

ไฟล์เสียงเป็น WAV 16-bit mono 48 kHz **เปิดได้โดยไม่ต้องใช้คีย์**
เบราว์เซอร์จึงโหลดเล่นเองได้ คีย์เก็บไว้ที่เซิร์ฟเวอร์ที่เดียว

> ข้อความซ้ำจะได้ `"จากแคช": true` คือไม่ต้องสังเคราะห์ใหม่ เร็วกว่ามาก

## 2. ข้อมูลที่ AI ตัวนี้เข้าถึงได้ (ด้วยคีย์ปัจจุบัน)

| สิ่งที่เก็บ | ค่า |
|---|---|
| ฟาร์ม | `kamphaengphet` |
| จุดวัด | `barn_R` (เล้า R 5/2) · `kamphaengphet_office` (สำนักงาน) |
| โซน | `inside` · `outside` |
| ความถี่ข้อมูล | เรียลไทม์ อัปเดตระดับนาที |

### ค่าที่วัดได้

| กลุ่ม | รายการ |
|---|---|
| อากาศในเล้า | อุณหภูมิ · ความชื้น · การไหลอากาศ (airflow) |
| คุณภาพอากาศ | แอมโมเนีย (NH₃) · คาร์บอนไดออกไซด์ (CO₂) |
| อากาศนอกเล้า | อุณหภูมิ · ความชื้น · ความเร็วลม · ทิศทางลม · ความเข้มแสง · ปริมาณฝน |
| ไฟฟ้า | กำลังไฟ (kW) · พลังงานสะสม (kWh) · กระแส A/B/C/เฉลี่ย · แรงดัน AB/BC/CA/เฉลี่ย · ความถี่ · เพาเวอร์แฟกเตอร์ |

### โครงสร้างเบื้องหลัง

- ฐานข้อมูล `Data_bases_kampangphet_Pig_01_2026`
- ตารางหลัก `data_realtime_raw`
- มีตารางสรุปสำเร็จรูป `data_Min_Max_Mean_Avg_12hrs`, `_24hrs` และช่วงอื่น ๆ
- เวลาเก็บเป็น UTC

## 3. ถามแบบไหนได้ผล

### ค่าปัจจุบันของจุดใดจุดหนึ่ง

> **ถาม:** ขอดูอุณหภูมิที่ กำแพงเพชร เล้า R 5/2 ตอนนี้

ได้ค่าทุกตัวของจุดนั้นพร้อมสถานะกำกับ (ปกติ / สูง / ระมัดระวัง)

```
อุณหภูมิ 24.41°C (ปกติ) · ความชื้น 91.33%RH (สูง)
NH₃ 0 ppm (ปกติ) · CO₂ 0 ppm (ปกติ) · การไหลอากาศ 0.38 m/s (ปกติ)
เวลา 16:59:45
```

### สรุปภาพรวมฟาร์ม

> **ถาม:** สรุปภาพรวมของฟาร์มให้หน่อย

ได้ทั้งในเล้า นอกเล้า **และข้อมูลไฟฟ้า**

```
ในเล้า  24.44°C · 91.49%RH (สูง) · NH₃ 0 ppm · CO₂ 0 ppm · ลม 0.17 m/s
นอกเล้า 30.40°C (ระมัดระวัง) · 88.20%RH (สูง)
ไฟฟ้า   กระแส 3.40–3.89 A · แรงดัน 391–396 V · 50.01 Hz
        เพาเวอร์แฟกเตอร์ 0.84 · พลังงานสะสม 7,890 kWh
```

### ตรวจสถานะเซนเซอร์

> **ถาม:** ตรวจสอบสถานะเซนเซอร์ทั้งหมด

บอกได้ว่าเซนเซอร์ตัวไหน **ข้อมูลค้าง** พร้อมเวลาล่าสุด

```
มีจุดที่ต้องดูแล (ตรวจ 2 จุด สำเร็จ 2 จุด)
- กำแพงเพชร สำนักงาน: ความเร็วลม / ทิศทางลม / ฝนขณะนี้ ข้อมูลไม่สด (ล่าสุด 16:35:04)
ปกติ: กำแพงเพชร เล้า R 5/2
```

### พยากรณ์อากาศ

> **ถาม:** ขอพยากรณ์อากาศกำแพงเพชร

ได้ค่าปัจจุบัน + พยากรณ์ล่วงหน้า 4 วัน (อุณหภูมิสูง-ต่ำ · โอกาสฝน % · ปริมาณ มม.)

### ขอไฟล์ CSV

> **ถาม:** ขอไฟล์ CSV ข้อมูลอุณหภูมิเล้า R

สร้างไฟล์ให้ดาวน์โหลด **ย้อนหลัง 24 ชั่วโมง** เปิดด้วย Excel ได้เลย

### ถามโครงสร้างข้อมูล

> **ถาม:** มีจุดวัดอะไรบ้าง / มี measure อะไรบ้าง

บอกชื่อตาราง แท็ก ฟิลด์ และค่าที่เป็นไปได้ทั้งหมด

## 4. ถามแล้วไม่ได้ผล

| ถาม | ได้ | เหตุผล |
|---|---|---|
| ความชื้นดินแสลงพัน | "ไม่พบแหล่งข้อมูลที่บัญชีนี้เข้าถึงได้" | คีย์ไม่มีสิทธิ์ |
| ประวัติย้อนหลัง 7 วันของเล้า R | "บัญชีนี้ไม่มีสิทธิ์เข้าถึง" | คีย์ไม่มีสิทธิ์ (แต่ CSV 24 ชม. ได้) |
| โรคสัตว์ / อาการ / วินิจฉัย | "ผมเป็นผู้ช่วยดูแลข้อมูลฟาร์มเท่านั้น" | ปฏิเสธโดยตั้งใจ ทดสอบแล้วทั้ง level 1, 2, 3 |

ระบบของเราจึง **ข้าม CPF ไปเลยเมื่อเป็นคำถามเรื่องโรค** แล้วตอบด้วยคลังคำอาการของฟาร์มเองแทน

## 5. ข้อควรรู้เวลาใช้งาน

### ถามตรง ๆ ดีกว่าตอบเลขเมนู

ถ้าถามกว้าง เช่น "อุณหภูมิตอนนี้เท่าไหร่" มันจะถามกลับเป็นเมนู

```
ต้องการดูอุณหภูมิอากาศที่จุดใดครับ
1. กำแพงเพชร สำนักงาน (เสาพยากรณ์อากาศ)
2. กำแพงเพชร เล้า R 5/2
```

**แต่ตอบ "2" ต่อไม่ได้** — มันจะขึ้นเมนูเดิมซ้ำ เพราะ API ไม่มีการจำบทสนทนา
(ทดสอบแล้วว่าแนบประวัติไปเองก็ไม่ช่วย)

ให้ถามระบุชื่อจุดไปเลยตั้งแต่แรก เช่น *"ขอดูอุณหภูมิที่เล้า R"*

### เวลาตอบไม่แน่นอน

| กรณี | เวลา |
|---|---|
| คำถามที่มีคำตอบสำเร็จรูป | 0.3 วินาที |
| ต้องไปดึงเซนเซอร์หลายตัว | 15–38 วินาที |

ถ้าใช้กับหน้าเสียง ควรมีข้อความบอกผู้ใช้ว่ากำลังดึงข้อมูลอยู่

### คำตอบมี Markdown ปนมา

ตอบมาเป็น `###` และ `**ตัวหนา**` ซึ่งอ่านออกเสียงแล้วแปลก
ถ้าจะเอาไปให้เสียงอ่าน ควรล้างสัญลักษณ์พวกนี้ออกก่อน

## 6. สรุปสั้น

**เหมาะกับ** — ค่าเซนเซอร์ปัจจุบัน · สถานะอุปกรณ์ · พยากรณ์อากาศ · ขอไฟล์ CSV

**ไม่เหมาะกับ** — เรื่องโรคสัตว์ · ข้อมูลย้อนหลังยาว ๆ · บทสนทนาต่อเนื่องหลายรอบ

**จุดแข็งที่สุด** คือมันต่อกับเซนเซอร์จริงของฟาร์มอยู่แล้ว
ข้อมูลที่ระบบเราดึงไม่ได้เพราะคีย์ `lab.plotnexuslab.com` หมดอายุ ตัวนี้ให้ได้ทันที
